## Preview locally
1. Extract this ZIP file.
2. Open the `PrimeLedger_Bookkeeping_Full_Website` folder.
3. Double-click `index.html` to open the website in a browser.

An internet connection is needed to load the optional Google Fonts. The website layout and content remain available without them.

## Contact form note
The inquiry form opens a pre-addressed email draft using the visitor's email application. It does not independently store form submissions or send them to a server. For a hosted form that collects inquiries online, connect a form-processing service before publishing.

## Publishing
Upload the contents of this folder (the `index.html`, `styles.css`, `script.js`, and `assets` folder) to a static website host such as GitHub Pages or Netlify. Do not upload the outer folder as a nested directory if your host expects `index.html` at the site root.
